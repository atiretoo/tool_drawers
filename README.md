# Tool Drawers

Parametric under-workbench shallow tool drawer system designed with CadQuery and 3D printed with Gridfinity modular organization.

## Project Overview

This repository contains the CAD design for a modular system of shallow, wide, and deep drawers mounted underneath a workshop workbench. Key design specifications and constraints include:
- **Workbench Base**: Built using standard dimensional 2x4 lumber and a tabletop repurposed from one half of a standard solid core door.
- **Drawer Organization**: Drawer interiors are fitted with [Gridfinity](https://gridfinity.xyz/) modular baseplates and bins.
- **Fabrication Constraints**: Printable modules are optimized for the **Prusa Core One** build volume, accommodating up to a **6 x 5 Gridfinity unit** footprint per print.
